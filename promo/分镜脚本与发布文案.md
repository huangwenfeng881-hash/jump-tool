## 可复现脚本

生成用的脚本都在 `promo_tmp/`：
- `gen_tts.py` — 配音生成（改文案后重跑）
- `build.py` — 卡片、背景乐、分镜裁切、拼接、烧字幕、混音一条龙
- `narration.json` — 每句配音的文本与时长
需要先装 ffmpeg 与 `E:\python\python.exe -m pip install edge-tts`。
