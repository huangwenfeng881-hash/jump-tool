## 同类游戏的通用机制拆解

灌篮/投篮类游戏（NBA 2K 的扣篮包、Basketball Stars、Dunk Shot 等）核心都是四层：

1. **输入时机层**：起跳点、起跳时机决定成败（Dunk Shot 是拖拽+松手时机；2K 是起跳距离+摇杆）
2. **物理预测层**：抛物线预测落点/高度，玩家能“看见”结果走向
3. **判定层**：摸高 vs 篮筐高度 + 判定区（球心/手部过框）
4. **反馈层（juice）**：命中特效、慢镜、震动、音效、分数飘字、连击

MVP 先把 **2 + 3** 做扎实（数值真实：站立摸高 + 弹跳 vs 305cm），反馈层留接口。

## 当前实现（v0.1）

- 输入：身高 / 臂展 / 体重 / 弹跳 / 站立摸高（可留空按臂展估算）
- 派生：站立摸高 ≈ 臂展 × 1.27；摸高 = 站摸 + 弹跳；需要 305 + 15 = 320cm
- 物理：v0 = √(2gh)，y(t) = v0t − ½gt²
- 流程：助跑 0.75s → 起跳 → 腾空 → 落地判定 → 显示「扣进 / 还差 X cm」
- 3D：程序化球场 + 篮架 + 卡通球员 + 篮球
