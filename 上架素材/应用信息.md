## 三、文案（复制用）

### 一句话简介（≤ 40 字）
```
AI 弹跳分析 + 扣篮潜力自测，手机拍一段就能测出弹跳高度
```

### 应用介绍（长文案）
```
【AI 弹跳分析 · 视频不上传】
用手机拍一段起跳视频，App 在本机逐帧识别，自动算出弹跳高度、起跳方式、起跳角度、摆臂速度、最后两步节奏和落地稳定性。全程本地运算，视频不会上传到任何服务器。

【扣篮潜力自测 · 3 个指标】
对齐「立定跳远 / 摸高差 / 站立摸高」三个核心指标，中 2 个就是起飞线：
· 立定跳远 ≥ 260cm —— 看瞬时爆发力
· 助跑摸高 − 原地摸高 ≥ 15cm —— 看助跑转化，低于 15cm 说明发力逻辑有问题
· 站立摸高 ≥ 220cm —— 扣篮的先天硬件门槛
测完自动找出最弱的一项，并给出对应的训练动作。

【训练更省事】
· 弹跳测量、动作分析、杠铃测速、速度-力量曲线都在一个 App 里
· 进步曲线、训练记录、排行榜，一眼看到自己的变化
· 免登录也能用：本机记录、自测、分析全部离线可用

【适合谁】
想扣篮的篮球爱好者、练弹跳的健身人群、需要量化训练数据的体育生和教练。
```

### 关键词（各商店 5~10 个）

```
弹跳,扣篮,摸高,篮球训练,弹跳测试,摸高测试,运动分析,爆发力训练
```
