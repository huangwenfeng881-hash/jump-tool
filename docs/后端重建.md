## 历史方案（应急用）


Supabase 项目已经彻底删除，云端账号/同步/会员全部失效。仓库里已经准备好一键重建脚本。

## 你只需要做 3 分钟的手工部分

1. 打开 https://supabase.com/dashboard 注册并登录（邮箱 + 密码，可能要收邮件点确认）
2. 右上角头像 → Account → Access Tokens → Generate new token，复制 sbp_ 开头的那串
3. 把 token 粘贴到 D:\jump app\.supabase-token 这个文件里（只有一行，已加入 .gitignore）

## 然后一键执行

双击仓库根目录的 一键重建后端.bat，或命令行运行：node tools/setup-supabase.mjs

脚本会自动完成：

- 用 Management API 创建项目（新加坡区 / 免费档），自动生成数据库密码
- 轮询等待项目可用（1~3 分钟）
- 依次执行仓库里的 8 个 supabase-*.sql：建表、RLS 策略，以及 get_ai_status / consume_ai / refund_ai / redeem_invite / get_leaderboard / finalize_payment 等函数
- 把新的 URL + anon key 写回 js/supabase-config.js、SupabaseConfig.kt、_redirects、supabase/.temp/project-ref
- 打印项目地址、数据库密码和下一步命令

## 收尾（1 分钟）

git add -A
git commit -m "后端重建：新 Supabase 项目"
git push    （Netlify 自动部署，App 登录页刷新后自动切回云端账号）

再到 Supabase 控制台 Authentication → Providers → Email，关闭 Confirm email，注册后即可直接登录。

## 说明

- 免费档：2 个项目、500MB 数据库、每月 5GB 流量，对当前用量足够。
- 脚本可重复运行；同名项目已存在会报错，可加 --name vertrise2 换个名字。
- 免费项目 7 天无访问会被暂停，登录报错时到控制台点一下 Restore 即可。

## 不重建也能用

当前 v1.6.0 已经有本机账号降级方案：断网或无后端时照样能注册、登录、存记录、打卡，只是不跨设备同步。所以重建后端不是马上必须做的事。
